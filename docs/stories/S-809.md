## Goal
`npm run growth:report -- <folder>` reads the CSV files the owner exported from Google Search Console and
prints a Markdown report: traffic by page type, easy-win queries, and queries grouped by intent.
It works offline and sends nothing anywhere.

## Input
A folder containing the files from Search Console → Performance → Export → CSV:
`Queries.csv` (columns: Top queries, Clicks, Impressions, CTR, Position) and
`Pages.csv` (columns: Top pages, Clicks, Impressions, CTR, Position).
Match columns by header name, case-insensitively; `CTR` may be `4.5%`; numbers may contain thousands separators.
If a required column is missing, exit 2 and name it.

## Report sections (functions in `src/lib/searchReport.js`)
1. `byPageType(pages)` — classify each URL path:
   `/` home · `/visa-bulletin/<slug>/` bulletin · `/visa-bulletin/` archive · `/priority-dates/<line>/<area>/` category × area ·
   `/priority-dates/<line>/` category · `/country/…` country · `/check/` checker · `/planner/` planner · `/learn/…` learn · other.
   Output a table: type, pages, clicks, impressions, CTR (clicks ÷ impressions), average position weighted by impressions.
2. `easyWins(queries)` — queries with average position from 5 to 20 and at least 20 impressions, sorted by impressions,
   top 25: query, impressions, clicks, position.
3. `byIntent(queries)` — bucket each query by the first matching rule, and total clicks and impressions per bucket:
   | Bucket | Rule (lower-cased query) |
   |---|---|
   | predictions | contains `predict` or `forecast` or `expected` |
   | release timing | contains `when` and (`release` or `come out` or `out`) |
   | bulletin month | contains `visa bulletin` and a month name or a 4-digit year |
   | category × country | contains a category token (`eb1`…`eb5`, `eb-1`…`eb-5`, `f1`, `f2a`, `f2b`, `f3`, `f4`) **and** a country token (`india`, `china`, `mexico`, `philippines`, `row`, `rest of world`) |
   | category only | contains a category token |
   | country only | contains a country token |
   | how-to / meaning | starts with `what`, `how`, `why`, or contains `meaning` |
   | brand | contains `visapulse` |
   | other | everything else |
4. `zeroClick(queries)` — at least 100 impressions and 0 clicks, top 15 (titles or descriptions to improve).
5. `topPages(pages)` — top 15 by clicks.

The script prints a heading with the folder name, then each section as a Markdown table, then a line
"Rows read: <n> queries, <m> pages." It writes no file; the owner or an agent redirects the output into
`docs/growth/reviews/`.
