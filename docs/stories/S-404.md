# S-404 Social cards (link preview images)

| | |
|---|---|
| Status | READY |
| Size | M |
| Difficulty | Careful |
| Phase | 3 Launch |
| Needs | network access for one `npm install` (a dev-only package). S-302 optional (nicer text). |

## Goal
When someone pastes a VisaPulse link into WhatsApp, LinkedIn, Slack, Reddit or X, the preview should show a
clean 1200×630 image: a default card for most pages and one card per bulletin month with the month and the
advance / move-back counts. Link previews are a large part of bulletin-day sharing.

## Design
- Cards are drawn as SVG strings by a pure function, then converted to PNG at build time by a **dev-only** package.
- Cards are generated only when `SITE_URL` is set (preview images need absolute addresses) so ordinary local builds stay fast.
- No runtime dependency is added. Total build time must stay under 10 seconds.

## Files to touch
`src/site/socialCard.js` (new), `scripts/build-site.mjs`, `src/site/layout.js`, `src/site/pages.js`,
`package.json` / `package-lock.json` (via npm), `test/socialCard.test.js` (new), `test/site.test.js`.

## Steps
1. Install the rasteriser as a dev dependency: `npm install --save-dev @resvg/resvg-js`.
   If the install fails (no network), set the story to `BLOCKED (needs npm install of a dev dependency)` and stop.
2. `src/site/socialCard.js` (`// @ts-check`), pure:
   ```js
   /** @param {{ kicker: string, title: string, lines: string[], footer: string }} card @returns {string} SVG, 1200×630 */
   export function socialCardSvg(card)
   ```
   Layout: solid background `#10161d`; a 12 px accent bar `#62cbe0` on the left; kicker (28 px, `#a3b3bd`) at y=110;
   title (76 px, bold, `#eef5f8`) at y=220, wrapped by you into at most two lines of 22 characters (pass pre-split lines:
   split on spaces); up to three `lines` (40 px, `#c6d2d9`) from y=360 with 60 px spacing; footer (28 px, `#a3b3bd`) at y=580.
   `font-family="Helvetica, Arial, DejaVu Sans, sans-serif"`. Escape every text with `escapeHtml` from `./html.js`.
3. Cards:
   - default (`/og/default.png`): kicker `VisaPulse`, title `The Visa Bulletin, verified`, lines
     [`Priority dates for every category`, `History since 2002`, `Checked against the official page`], footer = the site host;
   - per bulletin month (`/og/visa-bulletin-<month>-<year>.png`): kicker `Visa Bulletin`, title `<Month Year>`,
     lines from `summariseMovement(view, previous)`: [`<A> moved forward`, `<R> moved back`, `<U> unchanged`]
     (when there is no previous month: [`Final Action Dates and Dates for Filing`]), footer
     `<host> · ${view.verified ? 'verified against the official page' : 'not yet verified'}`.
4. `scripts/build-site.mjs`, only when `siteUrl` is set:
   ```js
   const { Resvg } = await import('@resvg/resvg-js')
   const png = new Resvg(svg, { fitTo: { mode: 'width', value: 1200 }, font: { loadSystemFonts: true } }).render().asPng()
   ```
   Write the files with `writeFileSync` (binary). Print the count and the time taken in the build report.
5. `src/site/layout.js`: add an optional `image` parameter (a path). When `site.siteUrl` is set emit
   `<meta property="og:image" content="${site.siteUrl}${image ?? '/og/default.png'}">`,
   `<meta property="og:image:width" content="1200">`, `<meta property="og:image:height" content="630">`, and change
   `twitter:card` to `summary_large_image`. Without `siteUrl`, nothing changes (keep `summary`).
6. `bulletinPage`: pass `image: '/og/visa-bulletin-<slug>.png'` (use `periodSlug`). The home page uses the latest month's card.
7. `npm run check`, then `SITE_URL=https://example.org npm run build && npm run check:site` and open two PNG files to
   look at them (`Read` tool shows images). Text must be visible and not cut off.

## Tests to add

- `test/site.test.js`: with `liveSite`, a bulletin page contains `og:image` with an absolute `https://example.org/og/…png`
  and `summary_large_image`; with the default `site`, no `og:image`.

## Acceptance
- [ ] `SITE_URL=… npm run build` writes `/og/default.png` and one PNG per bulletin month, each 1200×630.
- [ ] `og:image` (absolute) and `twitter:card=summary_large_image` appear only when `SITE_URL` is set.
- [ ] No new entry under `dependencies` in `package.json` (dev dependency only).
- [ ] Build time with cards under 10 s (figure in the logbook).
- [ ] Two cards inspected by eye: readable text, nothing clipped.
- [ ] `npm run check` green.

## Pitfalls
- The rasteriser uses fonts installed on the machine. A build server with no fonts would draw **no text**. Add to the
  logbook under "Owner actions": "after the first deploy, open `/og/default.png` on the live site; if the text is missing,
  tell the next session" (the fix is to bundle one open-licence font file and pass it via `font.fontFiles`).
- `check-site` validates `href`/`src` only, so a wrong `og:image` path is not caught: assert the file exists in your test
  or in the build (throw if a referenced card was not written).
- Do not put a priority date, a prediction or the word "guaranteed" on a card.
