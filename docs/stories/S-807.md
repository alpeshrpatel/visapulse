## Goal
Make it one tap to share (a) a bulletin's summary and (b) a category × area cut-off as **plain text with a
link**, using the phone's own share sheet when available and "copy" otherwise.

## What gets shared
- Bulletin page:
  `<Month Year> Visa Bulletin (Final Action Dates): <A> moved forward, <R> moved back, <U> unchanged vs <Previous Month Year>. Tables and history: <page URL>`
- Category × area page:
  `<code> <area>, <Month Year> Visa Bulletin: Final Action <value>; Date for Filing <value>. History: <page URL>`
- Checker result: **only the cut-offs, never the visitor's priority date**:
  `<code> <area>, <Month Year> Visa Bulletin: Final Action <value>; Date for Filing <value>. Check your own date: <site>/check/#category=<slug>&area=<slug>`
All end with ` Not legal advice.`

## Files to touch
`src/site/components.js` (`shareBlock`), `src/site/pages.js`, `src/client/site.js`, `src/client/check.js`,
`src/site/site.css`, `test/site.test.js`.

## Steps
1. `shareBlock(text)` in `src/site/components.js` returns
   ```html
   <p class="share-row" data-share hidden data-share-text="…">
     <button type="button" class="button button-quiet" data-share-native hidden>Share</button>
     <button type="button" class="button button-quiet" data-share-copy>Copy as text</button>
     <span data-share-status role="status" aria-live="polite"></span>
   </p>
   ```
   The text is built at build time **without** the page URL; the script appends `location.origin + location.pathname`
   (so it works on any host and never includes a fragment with a priority date).
2. `src/client/site.js`: for each `[data-share]`: unhide the row; if `navigator.share` exists unhide the native button
   and on click call `navigator.share({ text: fullText })` (ignore the rejection when the visitor cancels); the copy
   button uses `navigator.clipboard.writeText(fullText)` with the same fallback as S-307 (a read-only field selected for
   manual copy); status text "Copied." Export nothing; keep it self-contained.
3. Place the block: bulletin pages under the "What moved" paragraph (only when a previous month exists); category × area
   pages next to "Check my date".
4. Checker: after rendering a result, `check.js` builds the same row with `el()` using the text template above (cut-offs
   only) and the same handlers.
5. `site.css`: `.share-row` like `.cta-row`, smaller gap; hidden in print.
6. `npm run check`; test copy in the preview; if a phone-sized browser with `navigator.share` is not available, say so.

## Pitfalls
- `navigator.share` must be called directly from the click handler (a user gesture), not after an `await`.
- Keep the text under about 280 characters so it survives every messaging app's preview.
- No "Share on <network>" buttons that load third-party scripts.
