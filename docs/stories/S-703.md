## Goal
After "am I current?", people ask "how long does the next step take?". We do not copy those numbers (they
change, and the agencies' tools are the authority). We send people to the right official page for their path.

## Addresses (must be confirmed before use; do not trust this list blindly)
| Key | Purpose | Address to confirm |
|---|---|---|
| `uscisProcessingTimes` | USCIS case processing times tool | `https://egov.uscis.gov/processing-times/` |
| `nvcTimeframes` | National Visa Center timeframes | `https://travel.state.gov/content/travel/en/us-visas/immigrate/nvc-timeframes.html` |
| `dolProcessingTimes` | Department of Labor PERM processing times | `https://flag.dol.gov/processingtimes` |

Open each address in a browser tool (a person-style visit, not a script). If it loads the expected page, use it. If it
redirects, use the final address. If you have no browser tool, set the story to
`BLOCKED (owner: confirm three official addresses)` and list them under "Owner actions". Never guess a replacement.

## Files to touch
`src/site/format.js` (`OFFICIAL_LINKS`), `src/client/check.js`, `src/site/pages.js` (checker data + planner),
`src/GreenCardPlanner.jsx` (or `src/client/planner.js` if S-210 is done), `scripts/check-site.mjs`, `test/site.test.js`.

## Steps
1. Add the three confirmed addresses to `OFFICIAL_LINKS`.
2. Checker: add `officialLinks` (the three addresses) to the embedded JSON in `checkPage`. In `check.js`, under a result:
   - always: "Next: see the official processing times." with two links — "If you are adjusting status in the U.S.:
     USCIS processing times" and "If you are processing at a consulate: National Visa Center timeframes";
   - when the selected line's group is employment-based, also: "Employer still on labor certification (PERM)?
     Department of Labor processing times".
   Add one sentence: "These are the agencies' own figures. We do not copy or interpret them."
3. Planner: pass the links in `plannerBulletin`. Show the link that matches the selected `path` (adjustment → USCIS;
   consular → NVC) under the "next step" card, and the DOL link when the route is employment-based and the PERM status
   is not `certified`.
4. All external links: `rel="noopener"`, opening in the same tab (no `target`).
5. `scripts/check-site.mjs`: add a format-only rule for external links — every `href="http…"` in the built HTML must
   start with `https://` and must not contain a space; report violations. **Make no network request.**
6. `npm run check`.

## Tests to add
- The checker page's embedded JSON contains the three keys, each an `https://` address.
- `OFFICIAL_LINKS` values all start with `https://` and belong to hosts ending in `.gov`.

## Acceptance
- [ ] Checker and planner results link to the official page that matches the selected path.
- [ ] No processing-time number is copied onto the site.
- [ ] The three addresses were confirmed by opening them (logbook says who/how and the date), or the story is `BLOCKED`.
- [ ] `check-site` validates external link format without making requests.
- [ ] `npm run check` green.

## Pitfalls
- Government addresses move. Record the date each was confirmed in a comment next to `OFFICIAL_LINKS`.
- Do not deep-link to a specific form or office inside the USCIS tool; link to the tool's start page.
