|---|---|
| Status | READY |

| Why (growth) | The title and description are the whole advertisement in a search result. Ours should carry the answer (the date) and the month. See `docs/growth/SEO.md`, "On-page templates". |

## Goal
Rewrite page titles and meta descriptions to fixed templates, and add tests that keep them unique and within
sensible lengths.

## Templates (the layout adds ` | VisaPulse` to every title except the home page)
| Page | Title | Description |
|---|---|---|
| Home | `<Month Year> Visa Bulletin: priority dates and movement \| VisaPulse` (unchanged) | unchanged |
| Bulletin month | `Visa Bulletin <Month Year>: every priority date and what moved` | unchanged (or the S-302 short text) |
| Category × area, cut-off is a date | `<code> <area> priority date: <formatted date> (<Mon YYYY> bulletin)` | `<code> <area> Final Action Date is <date> in the <Month Year> Visa Bulletin<, Date for Filing <date>>. Movement, every retrogression and month-by-month history.` |
| Category × area, Current / Unavailable | `<code> <area> priority date: <Current\|Unavailable> (<Mon YYYY> bulletin)` | same pattern with the word |
| Category | `<code> priority dates by country, <Month Year>` | unchanged |
| Checker | unchanged | unchanged |
| Archive | unchanged | unchanged |

`<Mon YYYY>` is the three-letter month, for example `Jun 2025`. Area names in titles use `area.name`; for `all` use
`All Chargeability`. For the two longest codes use the short forms `EB-3 Other Workers` → as is; if a title would exceed
70 characters before the suffix, drop the bracketed bulletin part.

## Files to touch
`src/site/pages.js`, `src/site/format.js` (a `shortPeriod(period)` helper → `Jun 2025`), `test/site.test.js`.

## Steps
1. Add `shortPeriod` with a test.
2. Change the `title` and `description` arguments in `bulletinPage` (non-home), `lineAreaPage`, `linePage` to the templates.
3. Add a test that renders **every** page the build produces (loop the same lists the build uses: all periods, all
   lines, all line × area pairs, the fixed pages) and asserts:
   - all `<title>` texts are distinct;
   - each title is at most 70 characters before ` | VisaPulse`;
   - each meta description is between 50 and 160 characters;
   - no title or description contains `undefined`, `NaN`, two spaces in a row, or the words `wait time`, `prediction`, `forecast`.
4. `npm run check`. Spot-check three pages' `<title>` in the built HTML.

## Acceptance
- [ ] Category × area titles carry the current value and the bulletin month.
- [ ] Bulletin titles lead with "Visa Bulletin <Month Year>".
- [ ] The whole-site test enforces uniqueness and length limits.
- [ ] `npm run check` green.

## Pitfalls
- The existing test `category and area page…` asserts `<h1>` text, not titles; `<h1>` headings do not change in this story.
- Do not stuff synonyms into titles ("green card, visa, priority date, cut-off…"). One clear statement.
- A sitemap `<lastmod>` is **not** part of this story: we have no reliable modification dates until S-806 records them.
