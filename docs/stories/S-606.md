# S-606 Embeddable cut-off card

## Goal
Attorneys and bloggers write about one category and country over and over. Give them a tiny card they can
embed with an `<iframe>`: the current cut-offs, the bulletin month, the verification status, and a link back.
Every embed is a visible, relevant link to VisaPulse (see `docs/growth/OUTREACH.md`).

## Design
- `/embed/<lineSlug>/<areaSlug>/` (light) and `/embed/<lineSlug>/<areaSlug>/dark/` (dark): 150 small pages.
- **No JavaScript at all.** Its own minimal inline CSS (no site stylesheet, no header, no footer navigation).
- Framing is allowed for `/embed/*` only. Every other page keeps `X-Frame-Options: DENY`.
- The card updates by itself each month because the site is rebuilt.

## Card content
```
EB-2 India · Visa Bulletin for June 2025
Final Action Date     Jan 1, 2013
Date for Filing       Feb 1, 2013
Verified against the official bulletin · Not legal advice
History and details at VisaPulse →            (link, target="_top" rel="noopener", to the line × area page)
```

## Files to touch
`src/site/embed.js` (new), `src/site/format.js` (`urls.embed(line, area, dark?)`), `scripts/build-site.mjs`,
`scripts/check-site.mjs`, `public/_headers`, `src/site/pages.js` (snippet on line × area pages), `src/client/site.js`
(copy button), `src/site/site.css`, `test/site.test.js`.

## Steps
1. `src/site/embed.js`: `embedPage({ site, dataset, line, area, dark })` returns a **complete document without `layout`**:
   `<!doctype html>`, `<html lang="en">`, `<meta charset>`, viewport, `<title>EB-2 India priority date | VisaPulse</title>`,
   `<meta name="robots" content="noindex">`, a canonical link to the line × area page (when `siteUrl` is set), one
   `<style>` block (system font, 14 px, max-width 360 px, a border, colours for light or dark), and the card.
   Use an `<h1>` for the first line (the checker requires exactly one) and a `<dl>` for the two values.
   The words "Not legal advice" must be in the card.
2. `scripts/build-site.mjs`: add both variants for every `LINES` × `AREAS` to `pages`, but **exclude `/embed/` paths from
   the sitemap** (`indexable` filter).
3. `scripts/check-site.mjs`: it requires a meta description on every page. Either add a description meta to the embed
   document or exempt paths starting with `/embed/` from that one rule. Prefer adding the meta (simpler, no rule change).
4. `public/_headers`: the file applies header blocks by path. Replace the single `/*` block's `X-Frame-Options: DENY`
   approach with:
   ```
   /*
     X-Content-Type-Options: nosniff
     Referrer-Policy: strict-origin-when-cross-origin
     Permissions-Policy: camera=(), microphone=(), geolocation=(), interest-cohort=()
     Content-Security-Policy: frame-ancestors 'none'

   /embed/*
     ! Content-Security-Policy
     Content-Security-Policy: frame-ancestors *; default-src 'none'; style-src 'unsafe-inline'
   ```
   (`frame-ancestors` is the modern replacement for `X-Frame-Options`. The `! Header-Name` line is the Cloudflare Pages
   way to drop a header inherited from a broader rule; **other hosts differ**, so if the owner chose another host, read
   that host's `_headers` documentation and write the equivalent, or mark this step "needs the owner's host".)
   Remove `X-Frame-Options: DENY` from `/*`, because a blanket DENY would also block the embed pages.
   **Record this header change as decision D36** and list under "Owner
   actions": "after deploying, check with `curl -sI` that `/` sends `frame-ancestors 'none'` and `/embed/eb2/india/`
   sends `frame-ancestors *`" (this cannot be tested locally; `npm run dev` sends no headers).
5. Line × area page: add a collapsed `<details class="embed-snippet">` "Embed this on your site" containing a read-only
   `<textarea>` with
   `<iframe src="<siteUrl>/embed/<line>/<area>/" width="360" height="190" style="border:0" loading="lazy" title="EB-2 India priority date from VisaPulse"></iframe>`,
   a note "Add `dark/` to the address for a dark card. Updates automatically each month.", and a "Copy" button
   (reuse the copy pattern from S-307 if done; otherwise a small handler in `site.js`). Show the block **only when
   `site.siteUrl` is set** (the snippet needs an absolute address).
6. `npm run check`. Open two embed pages directly, light and dark, at 360 px wide.

## Tests to add
- `embedPage` output: contains no `<script`; contains exactly one `<h1>`; contains "Not legal advice"; contains the
  current Final Action value for EB-2 India from the dataset; the link has `target="_top"`.
- Gzip size of one embed page under 5 kB (`gzipSync(Buffer.from(String(page))).length < 5120`).
- With the default `site`, the line × area page has no `embed-snippet`; with `liveSite` it has the absolute iframe address.

## Acceptance
- [ ] `/embed/<category>/<area>/` and its `dark/` variant exist for all 75 pairs, script-free, under 5 kB gzip each.
- [ ] Each shows current cut-offs, the month, verification status and an attribution link.
- [ ] "Embed this" snippet on category × area pages (only with `SITE_URL`).
- [ ] Headers allow framing for `/embed/*` only; D36 recorded; owner check listed.
- [ ] Embed pages are `noindex` and not in the sitemap.
- [ ] `npm run check` green.

## Pitfalls
- The embed must not load the site stylesheet or script (page weight and the "script-free" promise).
- A framed page cannot set the parent's size. The card must fit 360×190 at the default font size; test long values such as "Unavailable".
- Do not add the sponsor block to embed pages.
