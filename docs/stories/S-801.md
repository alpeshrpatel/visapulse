## Goal
One page per chargeability area that shows **every** category for that country: `/country/india/`,
`/country/china/`, `/country/mexico/`, `/country/philippines/`, `/country/all-chargeability/`.

## Files to touch
`src/site/format.js` (`urls.countries = '/country/'`, `urls.country = (area) => `/country/${area.slug}/``),
`src/site/pages.js` (or new `src/site/countryPages.js`), `scripts/build-site.mjs`, `test/site.test.js`.

## Page content (`countryPage({ site, dataset, area })`)
1. Kicker: link "Priority dates". `<h1>`:
   - listed areas: `<Area name> green card priority dates`
   - `all`: `Priority dates for all other countries (All Chargeability)`
2. Lede: "Every family and employment category for people chargeable to <area longName>, from the <Month Year> Visa
   Bulletin, with movement since <Previous Month Year>." (drop the last clause when the previous month is missing).
   For `all` add: "If your country is not China, India, Mexico or the Philippines, this is your column."
3. `sourceLine(view)`.
4. Two tables (employment, family): one row per line of that group; columns `Final Action Date`, `Change`,
   `Date for Filing`, `Change`. Values from `getCutoff(view, line.key, chart, area.key)`; change =
   `movementChip(describeChange(now, previous))` against the previous month (`shiftPeriod(latest, -1)`).
   Row header links to the line × area page. Mark `viaAll` cells with † and the existing table note.
5. "What changed this month for <area name>": two short lists (moved forward, moved back) built from the same data,
   each item linking to the line × area page; "Nothing moved." when both are empty.
6. Two history charts (Final Action Dates), each with `chartLegend` and the sentence "This is what happened, not a
   forecast.": employment = EB-1, EB-2, EB-3, EB-4, EB-5 Unreserved; family = F1, F2A, F2B, F3, F4 (five series each —
   the chart supports five colours).
7. Buttons: "Check my date" (`/check/#area=<slug>`), "Plan my next step".
8. Related: links to the other four country pages.
Title: `<Area name> priority dates: every category, <Month Year> Visa Bulletin` (for `all`: `All Chargeability priority dates: …`).
Description: `Visa Bulletin cut-off dates for <area longName> in <Month Year>: EB-1 to EB-5 and F1 to F4, Final Action
Dates and Dates for Filing, with movement and history.`

## Steps
1. Add the URLs and the renderer; add a small index page at `/country/` listing the five areas with one line each
   (`<h1>Priority dates by country</h1>`).
2. Register the six pages in `build-site.mjs`.
3. Link to the hubs: column headers of the tables on `linesIndexPage` (each area name links to its hub); the "Related"
   block of `lineAreaPage` ("All categories for <area name>"); the home page hero, a line of five text links
   "By country: India · China · Mexico · Philippines · All other countries".
4. `npm run check`; look at India and All Chargeability at 375 and 1280, both themes.

- [ ] Each has the two history charts, the source line, and links to the checker with the area preselected.
- [ ] Linked from the home page, the priority-dates index and every category × area page.
- [ ] `npm run check` green (pages enter the sitemap automatically); visual check done.

## Pitfalls
- `check.js` restores `area` from the fragment only if the value matches an option: use the area **slug**.
- Do not write "India green card wait time" or any waiting-time phrase in titles or copy.
- Keep the page under about 25 kB gzip: two charts × five series is the heaviest part; do not add a third.
