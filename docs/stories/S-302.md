## Goal
Each bulletin page should say what happened in sentences a person can quote: how many lines moved, which
became Current or Unavailable, which had a cut-off imposed or reopened. The same text feeds the page's
meta description and the feed entry. Everything is generated from the data; no adjectives, no opinions.

## Already done
`summariseMovement(view, previous)` in `src/site/components.js` returns `{ total, advances, retrogressions, unchanged }`
for Final Action Dates. The bulletin page shows the counts and the top five of each.

## Files to touch
`src/lib/summary.js` (new), `test/summary.test.js` (new), `src/site/components.js`, `src/site/pages.js`,
`scripts/build-site.mjs`, `test/site.test.js`.

## Steps
1. Move the calculation into a pure module. Create `src/lib/summary.js` (`// @ts-check`):
   ```js
   /** @param {BulletinView} view @param {BulletinView | null} previous @param {Chart} [chart] default 'finalActionDates' */
   export function summariseMovement(view, previous, chart)   // same return shape as today
   /** @returns {{ headline: string, sentences: string[], short: string }} */
   export function writeSummary(view, previous, chart)
   ```
   `src/site/components.js` re-exports `summariseMovement` from the new module so existing imports keep working.
2. `writeSummary` uses only these templates. `<chart>` is "Final Action Dates" or "Dates for Filing";
   `<Month Year>` comes from `formatPeriod`; a "line" is written `<code> <area name>` (for example "EB-2 India").

   | Situation | Text |
   |---|---|
   | no previous month | headline: `<Month Year> is the first month in our data, so no movement is shown.` (no sentences) |
   | headline (always, when previous exists) | `<chart>, <Month Year> compared with <Previous Month Year>: <A> moved forward, <R> moved back and <U> did not move, out of <T> category and area pairs.` |
   | nothing moved (`A = 0` and `R = 0`) | sentence: `No <chart> cut-off changed.` |
   | largest advance in days (when one exists) | `The largest advance was <line>, <label> (<old> to <new>).` where label is `movement.label` |
   | largest retrogression in days (when one exists) | `The largest move back was <line>, <label> (<old> to <new>).` |
   | movement label "Became current" | `Became Current: <line>, <line> and <line>.` |
   | "Became unavailable" | `Became Unavailable: <list>.` |
   | "Cut-off imposed" | `Cut-off imposed where the category had been Current: <list>.` |
   | "Available again" | `Available again after being Unavailable: <list>.` |

   Lists use commas and "and" before the last item; when a list has more than six lines, write the first six followed by
   `and <n> more`. `short` is the headline's counts only, at most 155 characters:
   `<Month Year> Visa Bulletin, <chart>: <A> forward, <R> back, <U> unchanged vs <Previous Month Year>.`
   Old and new values are shown through `formatCutoff`. To keep `src/lib` free of site code, do not import it there:
   give `writeSummary` a last parameter `format` (default: return the value unchanged) and let the caller pass `formatCutoff`.
3. `src/site/pages.js`, `bulletinPage`:
   - in the "What moved" section, render the headline and sentences as a paragraph for Final Action Dates, then (when the
     month has a filing chart) a second paragraph for Dates for Filing; keep the existing two lists below;
   - `description` becomes `writeSummary(...).short` followed by
     ` ${view.verified ? 'Verified against the official State Department page.' : 'Not yet verified against the official page.'}`
     when a previous month exists; otherwise keep today's description.
4. `scripts/build-site.mjs`: in the feed, replace the fixed `<summary>` text with the Final Action `short` text for that
   period (escape with `escapeHtml`).
5. `npm run check`; read three bulletin pages (one normal month, one with a retrogression, 2015-10 or later for the second
   paragraph) and confirm each sentence against the tables on the same page.

## Tests to add (`test/summary.test.js`)

the table above: first month; nothing moved; an advance; a retrogression; became Current; became Unavailable; cut-off
imposed; available again; a list longer than six. Also: `short.length <= 155`; no output contains the words

In `test/site.test.js`: the June 2025 page contains the headline start `Final Action Dates, June 2025 compared with May 2025`
only if May 2025 is in the dataset; otherwise it contains the "first month" or "not in our data" wording already there.

## Pitfalls
- `describeChange` returns `days: null` for Current/Unavailable transitions. "Largest" means the largest absolute `days`
  among moves where `days` is a number.
- The previous month may be missing (withheld) — then there is no summary, as today. Do not compare against an older month.
- Meta descriptions are attribute values; `html` escapes them. In the feed you must call `escapeHtml` yourself.
