# S-110 Months the archive does not hold

| | |
|---|---|
| Status | BLOCKED (owner saves the official pages from a browser) |
| Size | S per month |
| Difficulty | Routine |
| Phase | 0 Foundation |
| Needs | The owner's saved HTML files |
| Unblocks | S-109 if the newest months are missing |

## Goal
Some bulletin months have no Internet Archive copy yet (on 2026-11-16: 2026-08 … 2026-12; later, any month for
which `npm run data:add` prints "no archived snapshot yet"). The pipeline may not fetch the State Department
site, so a person saves the page and the pipeline reads that file.

## Owner part (cannot be done by an agent)
For each missing month:
1. Open the official bulletin in a normal browser. The address pattern is
   `https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin/<fiscal year>/visa-bulletin-for-<month>-<year>.html`
   (October–December live in the *next* year's folder), or follow the link from the
   [bulletin index](https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin.html).
2. File → Save Page As → **"Webpage, HTML only"**. Name it `<YYYY-MM>.html`, for example `2026-12.html`.
3. Put the files in one folder and tell the agent the folder path (or leave them in `~/Downloads/visapulse-manual/`).

## Agent part (once the files exist)
For each file:
1. `npm run data:add -- <YYYY-MM> --file <path to the saved file>`
   This copies the bytes to `data/sources/manual/<YYYY-MM>.html`, records the hash in the manifest with
   `retrievedVia: "manual-file"`, parses, validates and cross-checks.
2. If the parser throws, do **not** edit the saved file. Report the message. (A new row or column is handled as in S-108 step 5.)
3. Open the saved HTML file in the browser pane (it is a local file) and compare **three cells** with the new record
   `data/bulletins/<YYYY>/<YYYY-MM>.json`: one family cell, one employment cell, one Dates for Filing cell. Write the three
   cells and their values in the logbook.
4. `npm run check`.

## Acceptance (per month)
- [ ] `data/bulletins/<YYYY>/<YYYY-MM>.json` exists with `source.retrievedVia` = `manual-file`.
- [ ] `data/sources/manual/<YYYY-MM>.html` exists and its SHA-256 equals the manifest entry (`npm run data:validate` proves it).
- [ ] Three cells compared by eye against the saved official page and listed in the logbook.
- [ ] `npm run check` green.

## Pitfalls
- "Webpage, Complete" also works but adds a folder of assets; only the `.html` file is needed.
- A page saved while logged in to a translation extension or with reader mode on is not the official bytes. If the
  title check fails ("page title … is not the Visa Bulletin for …"), ask the owner to save it again.
- If the owner does nothing, these months simply stay unverified (or absent once S-109 lands). That is acceptable.
