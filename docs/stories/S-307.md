## Goal
People pass these pages around in group chats and print them for attorneys. Give them a "Copy link" button
on checker results and category × area pages, and a print layout that keeps what matters.

## Files to touch
`src/client/site.js`, `src/client/check.js`, `src/site/pages.js`, `src/site/site.css`, `test/site.test.js`.

## Steps
1. `src/client/site.js`: add one generic handler:
   ```js
   // "Copy link" buttons. Hidden until JavaScript runs.
   for (const button of document.querySelectorAll('[data-copy-link]')) {
     button.hidden = false
     button.addEventListener('click', async () => {
       const status = button.parentElement.querySelector('[data-copy-status]')
       try { await navigator.clipboard.writeText(location.href); status.textContent = 'Link copied.' }
       catch { /* no clipboard permission: show the address so it can be copied by hand */
         const field = button.parentElement.querySelector('[data-copy-field]')
         field.hidden = false; field.value = location.href; field.select(); status.textContent = 'Press Ctrl+C or Cmd+C to copy.' }
     })
   }
   ```
2. `src/site/pages.js`: add a small helper `copyLink()` returning
   ```html
   <p class="copy-row">
     <button type="button" class="button button-quiet" data-copy-link hidden>Copy link</button>
     <input type="text" readonly hidden data-copy-field aria-label="Page address">
     <span data-copy-status role="status" aria-live="polite"></span>
   </p>
   ```
   Put it on `lineAreaPage` after the "Check my date" button row.
3. `src/client/check.js`: after a result is rendered, append the same three elements (built with the `el()` helper) under
   the result and wire the same behaviour (the fragment already holds the state, so `location.href` is the share link).
   Because these are created after `site.js` ran, attach the click handler in `check.js` itself.
4. Print (`@media print` block at the end of `site.css`). Make sure all of these hold, adding rules where missing:
   - hidden: `.site-header nav`, `.theme-toggle`, `.cta-row`, `.chart-switch`, `.feedback`, `.pager`, `.copy-row`,
     `.check-form`, `.related`, `.jump`;
   - shown: both chart panels (`.dates [data-chart-panel] { display: block !important; }` already exists);
   - `.table-scroll { overflow: visible; }` and `.table-tall { max-height: none; }` so tables are not cut;
   - `a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 0.8em; }` inside `.source-line` only, so the
     printed page shows the official address;
   - `body { background: #fff; color: #000; }`.
5. `npm run check`. Use print preview (or print-media emulation) on: a bulletin page, a category × area page, the checker with a result.

## Acceptance
- [ ] "Copy link" appears on category × area pages and under a checker result, only when JavaScript runs.
- [ ] Clicking it copies the address, or reveals a selected text field when the clipboard is not available.
- [ ] A status message is announced (`role="status"`).
- [ ] Printed bulletin, category × area and checker pages: no navigation or buttons; both charts' tables expanded and
      uncut; source line (with the official address) and the disclaimer kept.
- [ ] `npm run check` green; print checked on the three page types (say how: preview or emulation).

## Pitfalls
- `navigator.clipboard` exists only on secure origins (https and localhost). The fallback is not optional.
- Do not print link addresses for every link on the page (it makes tables unreadable): scope the rule to `.source-line`.
- The checker's copy button must copy the URL **with** the fragment. Read `location.href` at click time, not at render time.
