## Goal
Search is the main way people will find the site. The two webmaster consoles tell us whether pages are being
indexed and which searches show them. Setting them up needs the owner's accounts.

## Owner part (about 20 minutes)
1. **Google Search Console** → add a **Domain** property → verify with the DNS TXT record it gives you (add it at the
   domain registrar or DNS host). → Sitemaps → submit `https://<domain>/sitemap.xml`.
2. **Bing Webmaster Tools** → add the site → choose "Import from Google Search Console" (fastest) or verify by DNS →
   submit the same sitemap.
3. In Search Console → URL inspection, request indexing for: the home page, the newest bulletin page,
   `/priority-dates/eb2/india/`, `/priority-dates/eb3/india/`, `/priority-dates/f4/philippines/`, `/check/`.
4. Seven days later, export two reports as CSV and put them in `docs/growth/exports/` (create the folder):
   Pages (Indexing → Pages) and Queries + Pages (Performance, last 28 days).

## Agent part
1. Add to `docs/RUNBOOKS.md` a section **RB10 Monthly search check** with these steps:
   - Indexing → Pages: note "Indexed" and "Not indexed" counts and the top reason for not indexed.
   - Performance, last 28 days, filter Page contains `/visa-bulletin/`: impressions, clicks, average position.
   - Same for `/priority-dates/`, then `/check/`.
   - Top 20 queries by impressions with position between 5 and 20 (these are the easiest wins; see `docs/growth/SEO.md`).
   - Write the numbers into the monthly table in `docs/growth/METRICS.md`.
2. If the owner's exports exist in `docs/growth/exports/`, read them and write the first-week status in the logbook:
   pages indexed out of pages in the sitemap, and any "Crawled – currently not indexed" pattern (for example "all
   pre-2010 bulletin pages"). If S-809 is `DONE`, run its report on the export.
3. A verification **meta tag** or **HTML file**, if the owner prefers that method over DNS: add a build setting
   `SITE_VERIFICATION` (JSON object name → content, names limited to `google-site-verification` and `msvalidate.01`)
   emitted as `<meta name="…" content="…">` on the home page only; absent when unset; with a test. Do this only if asked.

## Acceptance
- [ ] Both consoles verified and the sitemap submitted (owner confirms).
- [ ] RUNBOOKS RB10 exists.
- [ ] First-week indexing status logged (or "exports not provided yet").

## Pitfalls
- Never ask for, store or type the owner's Google or Microsoft password. The owner signs in.
- Verification tokens are public values but belong in the host's build settings, not in the repository.
- A new site commonly takes days to weeks to be indexed. A low first-week count is not a bug by itself.
