## Goal
Show, next to a category × area cut-off, the official count of people waiting — as context, with its
publication date and its limits stated. Ingest it with the same discipline as the bulletin: pinned copy,
hash, a parser that refuses to guess, a validator, and provenance on the page.

## Before you start
Open `docs/data/SOURCES.md`. This story uses the source S-701 ranked first for demand (expected to be the State
Department's annual waiting-list report or a USCIS inventory report). If no demand source has a GO verdict, stop.
Read the source's own notes on what the numbers include and exclude; those notes become the on-page caveats.

## Design (mirror the bulletin pipeline; do not invent a new one)
| Bulletin pipeline | This dataset |
|---|---|
| `scripts/fetch-archive.mjs` + `data/sources/manifest.json` | `data/sources/demand-manifest.json`: edition → official URL, archive snapshot or `manual-file`, SHA-256, bytes |
| `.cache/official/` and `data/sources/manual/` | `.cache/demand/` and `data/sources/manual-demand/` (PDFs or pages a person saved) |
| `src/lib/parseBulletin.js` | `src/lib/parseDemand.js`: throws on any unknown row, column or cell |
| `data/bulletins/YYYY/YYYY-MM.json` | `data/demand/<edition>.json` with a provenance block |
| `src/lib/validateBulletin.js` | `src/lib/validateDemand.js`, wired into `scripts/validate-data.mjs` |

Record shape:
```json
{ "schemaVersion": 1, "edition": "2025", "asOf": "2025-11-01", "title": "…as printed…",
  "source": { "publisher": "…", "officialUrl": "…", "retrievedVia": "…", "sha256": "…", "parserVersion": 1 },
  "notes": ["…caveats quoted from the publication…"],
  "counts": { "EB2": { "india": 123, "all": 456 }, "F4": { … } } }
```

## Steps
1. Obtain the document only by a route S-701 approved (archive snapshot or a file the owner saved). One document, not a crawl.
2. If the source is a PDF: extract text with a dev-only tool available in the session; if none is available, set the
   story to `BLOCKED (needs a PDF text extractor or a hand-saved table)`. Never retype numbers by hand.
3. Write the parser against the real document. Map its category and country labels to `LINES` keys and `AREAS` keys
   explicitly; an unmapped label throws. Countries that are not one of the four listed areas are **not** summed into
   `all` unless the publication itself prints a worldwide or "all other" total — use the printed total.
4. Fixture test: the saved document (or its extracted text) goes in `test/fixtures/demand/`; assert five numbers you
   read with your own eyes in the document, and that the parser throws on a tampered copy.
5. Validator: integers ≥ 0; known keys only; `asOf` a real date; hash matches the manifest.
6. Page: on each category × area page, a card "People waiting (official count)": the number, "as of <date>", the
   publication name as a link, and the quoted caveats. When the publication has no figure for that pair, show nothing.
   Under it, always: "This is a count, not a waiting time. It cannot be turned into an estimate: not everyone counted
   will apply, and visa numbers are allotted across categories and countries each year."
7. Methodology page: a section on this dataset (source, how it is checked, limits). Open-data page: link `/data/demand/<edition>.json`.
8. `npm run check`.

## Acceptance
- [ ] One official edition ingested through a pinned copy with a hash; nothing typed by hand.
- [ ] Parser refuses unknown labels; fixture test with five eye-checked numbers.
- [ ] Validator runs in `npm run data:validate`.
- [ ] The count appears on category × area pages with its date, source link and quoted caveats.
- [ ] **No estimate anywhere**: a test asserts the page does not match `/\b(years?|months?) (of )?wait|at this rate|estimated/i` in the new section.
- [ ] Methodology and open-data pages updated. `npm run check` green.

## Pitfalls
- Dividing a count by an annual limit is the classic naive estimator this project exists to avoid (decision D27).
- Different reports count different things (principal applicants only, or with dependents; at NVC only, or also in the
  U.S.). Quote the report's own definition; do not harmonise two reports.
