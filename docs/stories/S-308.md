## Goal
1. Build a small, reusable way to publish explanation pages under `/learn/<slug>/`, with a safety catch:
   a page is **not built** until a person has reviewed it (`reviewedOn` set).
2. Write the first one: "Which chargeability area am I?" — why the checker asks for an "area" and why it is
   usually, but not always, the country of birth. Linked from the checker and the planner.

## Why the safety catch
Explanations of immigration rules are the easiest place for a wrong sentence to hurt someone. Every factual
sentence must come from an official text and link to it, and a person signs off before visitors see it.

## Part 1 — framework
1. `src/site/explainers.js` (`// @ts-check`):
   ```js
   /**
    * @typedef {{
    *   slug: string, title: string, description: string,
    *   draftedOn: string,            // ISO date the text was written
    *   reviewedOn: string | null,    // ISO date a PERSON approved it. null = not published
    *   sources: { id: string, label: string, url: string }[],   // official texts only
    *   body: (cite: (id: string) => SafeHtml) => SafeHtml,
    * }} Explainer
    */
   export const EXPLAINERS = [ /* entries */ ]
   export function publishedExplainers(showDrafts)   // reviewedOn set, or all when showDrafts is true
   export function explainerPage({ site, explainer })
   export function explainersIndexPage({ site, explainers })
   ```
   - `cite('ina-202b')` returns a superscript link `<sup><a href="#src-ina-202b">[n]</a></sup>` where `n` is the source's
     position; it **throws** if the id is not in `sources`.
   - `explainerPage` renders: kicker "Learn", `<h1>`, the body, a "Sources" ordered list (`id="src-<id>"`, link with
     `rel="noopener"`), the line `Last reviewed <date>` (or, for a draft shown with `SHOW_DRAFTS`, a visible banner
     `DRAFT — not reviewed, not published`), and a closing paragraph: "This page describes published rules in general
     terms. It is not legal advice and cannot tell you how the rules apply to you."
   - Allowed source hosts (enforced by a function `validateExplainer` and a test): `travel.state.gov`, `fam.state.gov`,
     `www.uscis.gov`, `www.ecfr.gov`, `uscode.house.gov`, `www.govinfo.gov`, `www.federalregister.gov`, `www.dol.gov`,
     `www.congress.gov`. Each must be `https`.
   - `validateExplainer` also requires: slug `^[a-z0-9-]+$`; description 50–160 characters; at least one source;
     every source id used at least once in the body (render the body with a recording `cite`).
2. `urls.learn = '/learn/'` and `urls.explainer = (slug) => `/learn/${slug}/``.
3. `scripts/build-site.mjs`: `const showDrafts = process.env.SHOW_DRAFTS === '1'`; build one page per
   `publishedExplainers(showDrafts)` and the index page **only if** that list is not empty. Draft pages get `noindex: true`.
   Document `SHOW_DRAFTS` in `.env.example` ("local preview only; never set on the host").
4. Links from other pages to an explainer must be conditional: export `explainerLink(slug, text, showDrafts)` that
   returns the link when the explainer is published and an empty string otherwise (otherwise `check-site` fails on a broken link).
5. `test/explainers.test.js`: `cite` throws on an unknown id; `validateExplainer` rejects a non-official host, a missing
   source, an unused source; an explainer with `reviewedOn: null` is absent from `publishedExplainers(false)` and present
   with `true`; a rendered page contains "Sources", the disclaimer sentence and exactly one `<h1>`; **every entry in
   `EXPLAINERS` passes `validateExplainer`**.

## Part 2 — the chargeability page (slug `chargeability`)
Title: `Which chargeability area am I?`
1. **Read the official text first.** The rule is in INA § 202(b) (8 U.S.C. § 1152(b)) and the State Department
   regulation 22 CFR § 42.12. Fetch the text from an allowed host that permits reading (try `https://www.ecfr.gov/current/title-22/section-42.12`
   and `https://uscode.house.gov/` for 8 U.S.C. 1152). Do not fetch `travel.state.gov` or `uscis.gov` with a script.
2. If you **could not read** an official text in this session: create the entry with the structure and source list but a
   body that contains only the first paragraph below (which states nothing about the law beyond what the bulletin itself
   prints), set the story to `BLOCKED (needs a person or a model that can read 22 CFR 42.12)`, and stop.
3. If you could read it, write the body with these sections. Each sentence that states a rule ends with `cite(...)`.
   Quote or closely paraphrase; add nothing from memory.
   - **What "chargeability area" means on this site** — the bulletin lists some countries separately; everyone else is
     under "All Chargeability Areas Except Those Listed" (this comes from the bulletin page itself; cite the bulletin index).
   - **The general rule** — chargeability is normally determined by place of birth, not citizenship (cite).
   - **The exceptions the regulation lists** — one short bullet per exception, in the regulation's own terms
     (for example accompanying spouse, accompanying child, birth in a country where neither parent was born or resided).
     Only the exceptions you actually read. No examples of who "qualifies".
   - **What this page cannot tell you** — whether an exception applies to a person depends on facts and is decided by the
     government; talk to a licensed immigration attorney.
4. Leave `reviewedOn: null`. Set `draftedOn` to today's date.
5. `src/site/pages.js`: on the checker (under the area select) and in the planner hero add
   `explainerLink('chargeability', 'Which area am I?', showDrafts)` (pass `showDrafts` through `site`: add
   `showDrafts: boolean` to `SiteContext` and the test fixtures).
6. Preview with `SHOW_DRAFTS=1 npm run dev`; check `/learn/chargeability/` at 375 and 1280.

## Pitfalls
- Never set `reviewedOn` yourself, in this or any later story.
- Do not cite a law-firm article, Wikipedia, or a forum. Official hosts only (the validator enforces it).
- The built-site check requires exactly one `<h1>`; the body uses `<h2>` and lower.
