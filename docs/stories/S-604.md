## Goal
A short guide for each main category — EB-1, EB-2, EB-3, EB-4, EB-5, F1, F2 (A and B), F3, F4 — that says who
the category covers and how its visa numbers are limited, shows the current cut-offs from our data, and links
to the official text for every statement. No eligibility advice.

## Rules for this story
- Each guide is an entry in `EXPLAINERS` (`src/site/explainers.js`) with slug `guide-<category>` (for example
  `guide-eb2`), `reviewedOn: null`. It is not published until the owner reviews it.
- **Every factual sentence ends with a citation** to an allowed official host (the framework's validator lists them).
- Write only what you read in the cited text during this session. If you cannot read a source, leave that section out
  and list it in the logbook.
- Do one guide completely before starting the next. It is fine to finish this story with fewer than nine guides, as long
  as the logbook says which remain.

## Sources to read (per guide)
| Topic | Where the official text is |
|---|---|
| Who the category covers | INA § 203(a) (family) or § 203(b) (employment) — 8 U.S.C. § 1153 at `uscode.house.gov` |
| Share of the annual limit | the same sections (each preference's percentage) and INA § 201 (8 U.S.C. § 1151) for the worldwide levels |
| Per-country limit | INA § 202(a)(2) (8 U.S.C. § 1152) |
| The plain-language description the government itself uses | the "Statutory numbers" section printed in every Visa Bulletin; read it from a fixture in `test/fixtures/official/2025-06.html` (already in the repository) and cite the bulletin's official URL for that month |

The Visa Bulletin fixture is the easiest source: section A of every bulletin lists each preference with its description
and percentage. Quote from it.

## Files to touch
`src/site/explainers.js`, `src/site/pages.js` (links from line pages), `test/explainers.test.js`.

## Steps (per guide)
1. Extract the bulletin's own description of the category from the fixture (the page prints, for example,
   "First : Priority Workers: 28.6% of the worldwide employment-based preference level, plus …"):
   ```bash
   node -e "import('./src/lib/extractTables.js').then(({toText})=>{const t=toText(require('fs').readFileSync('test/fixtures/official/2025-06.html','utf8'));for(const k of ['FAMILY-SPONSORED PREFERENCES','EMPLOYMENT-BASED PREFERENCES','per-country limit']){const i=t.indexOf(k);console.log('\n== '+k+'\n'+t.slice(i,i+1600))}})"
   ```
   Read the printed text and quote from it.
2. Add the entry. Body sections (all `<h2>`):
   - **Who it covers** — the bulletin's description, quoted, with the citation.
   - **How many visas** — the percentage or number as the bulletin states it; the per-country limit sentence as the
     bulletin states it. Citations to the bulletin and, if you read it, the statute section.
   - **Current cut-offs** — *not written by hand*: a function in the explainer body receives the dataset and renders the
     latest Final Action and Dates for Filing cut-offs for the five areas with `cutoffValue`, each linking to the
     line × area page. (Extend the `body` signature to `(cite, context)` where `context = { dataset }`.)
   - **Sub-lines on this site** — for EB-3 mention the "Other Workers" line; EB-4 "Certain religious workers"; EB-5 the
     unreserved line and the three set-asides; F2 the split into F2A and F2B. Only as "the bulletin lists these rows
     separately", with a link to each page.
   - **Questions people ask** — two or three, answered only with facts already on the page and links to the checker,
     the chargeability explainer and the official USCIS page (`OFFICIAL_LINKS.uscisPriorityDates`). No "should I…" answers.
3. Link each guide from its line page (`linePage`) with `explainerLink(...)` (empty until published).
4. `SHOW_DRAFTS=1 npm run dev` and read the page once, top to bottom, against the sources.

## Pitfalls
- Percentages and limits are the most-copied wrong facts on the internet. Copy them only from the bulletin fixture or the statute.
- Do not describe processing steps, forms or fees: that is advice-adjacent and changes often.
- The bulletin fixture is from June 2025. If a later bulletin words a category differently, the newer official wording wins; say which month you quoted.
