# S-803 Question-and-answer block on category × area pages

| | |
|---|---|
| Status | READY |
| Size | S |
| Difficulty | Routine |
| Phase | 7 Growth engineering |
| Needs | nothing |
| Why (growth) | People type full questions ("what is the EB2 India priority date in June 2025", "has F2A ever been current"). A page that states the question and the answer in words matches those searches and is quotable in chats. See `docs/growth/SEO.md`, page type P2. |

## Goal
On every category × area page, a "Questions" section with five questions, each answered in one or two
sentences **generated from the data**. No hand-written answers, no structured-data markup.

## Files to touch
`src/lib/answers.js` (new, pure), `test/answers.test.js` (new), `src/site/pages.js` (`lineAreaPage`), `src/site/site.css`.

## The five questions (`name` = `<code> <area name>`, `Month Year` = latest bulletin)
| # | Question | Answer template |
|---|---|---|
| 1 | What is the `name` priority date in the `Month Year` Visa Bulletin? | `The Final Action Date is <value>` + (when a filing value exists) ` and the Date for Filing is <value>` + `.` When the value is Current: `<name> is Current on Final Action Dates: there is no cut-off this month.` When Unavailable: `<name> is Unavailable on Final Action Dates: no visa numbers can be used this month.` |
| 2 | Did `name` move in `Month Year`? | `Compared with <Previous Month Year>, the Final Action Date <phrase>.` Phrases by movement: advance with days → `moved forward <label without sign> (from <old> to <new>)`; retrogression with days → `moved back <label without sign> (from <old> to <new>)`; unchanged → `did not move`; other labels → the label in lower case. No previous month → `<Previous Month Year> is not in our data, so we cannot say.` |
| 3 | When did `name` last move backwards? | `The Final Action Date last moved back in <Month Year> (from <old> to <new>).` or `It has not moved back in the months on record.` |
| 4 | Has `name` ever been Current? | `Yes. It was last Current in the <Month Year> bulletin.` or (if Current now) `Yes. It is Current now.` or `Not in the months on record (<first Month Year> to <last Month Year>).` |
| 5 | How do I know if my priority date is current? | `Your date is current when it is earlier than the cut-off. A date equal to the cut-off is not current yet.` + link "Check my date" (to the checker with this line and area) |

Values are shown with `formatCutoff`. "Label without sign" = `movement.label` with the leading `+` or `−` removed.

## Steps
1. `src/lib/answers.js`: `lineAreaAnswers({ name, points, filingPoints, latest, format })` → `[{ question, answer }]`
   for questions 1–4 (question 5 is static and added by the page because it contains a link). `points` and
   `filingPoints` come from `dataset.series(...)`. Pure; no HTML.
2. `test/answers.test.js`: one test per branch of each template (date, Current, Unavailable; advance, retrogression,
   unchanged, became current, missing previous month; a past retrogression and none; Current now, Current in the past, never).
3. `lineAreaPage`: after the "Retrogressions" section add
   ```html
   <section class="qa"><h2>Questions about <name></h2>
     <h3>question</h3><p>answer</p> …
   </section>
   ```
   If the latest month is unverified add the sentence already used elsewhere: "Based on data not yet verified against the official page."
4. `site.css`: `.qa h3 { margin: 16px 0 4px; font-size: 1rem; }`.
5. `npm run check`; read the section on EB-2 India, F2A Mexico and EB-1 All Chargeability and confirm each answer
   against the tables on the same page.

## Tests to add (`test/site.test.js`)

## Acceptance
- [ ] Five questions on every category × area page; answers 1–4 generated from data.
- [ ] Every template branch has a unit test.
- [ ] No structured-data markup added; no prediction or advice in any answer.
- [ ] Three pages read and checked by hand; `npm run check` green.

## Pitfalls
- Do not add `FAQPage` JSON-LD. Search engines show that feature only for a narrow set of sites, and markup generated
  at scale without it being the page's main content is treated as low quality.
- "Has it ever been Current" is limited to the months on record. Always include the range when the answer is "not".
