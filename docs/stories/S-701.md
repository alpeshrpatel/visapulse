## Goal
The bulletin says where the line is, not how long it is. Other official publications say how many people
are waiting and how many visas were used. Before ingesting any of them, find out exactly what exists, in
what format, under what terms, and whether we can obtain it without breaking decision D19 (we never script a
site that refuses scripts). The output is one document with a go / no-go per source.

## Candidates to study (all U.S. government publications)
1. USCIS processing times (the "Check Case Processing Times" tool).
2. USCIS reports on pending Form I-485 inventory and on approved employment-based petitions awaiting a visa number.
3. State Department "Annual Report of Immigrant Visa Applicants in the Family-sponsored and Employment-based
   preferences Registered at the National Visa Center" (the waiting-list report).
4. State Department annual numerical limits notice for the fiscal year.
5. State Department "Report of the Visa Office" statistical tables (immigrant visas issued by category and country).
6. Department of Labor PERM processing times and the quarterly disclosure data.
7. DHS Yearbook of Immigration Statistics (adjustments of status by category), as a cross-check for 5.

## Steps
1. For each candidate, find the official page. Start from the agency's own site navigation or the Internet Archive
   (`https://web.archive.org/web/2026*/<address>`); do not rely on a memory of the address.
2. For each, record in `docs/data/SOURCES.md` using exactly this template:
   ```
   ## <n>. <Name>
   - Publisher:
   - Address (as opened on <date>):
   - What it contains (one paragraph, in your own words, from what you read):
   - Granularity: by category? by country of chargeability? by month, quarter or year?
   - Format: HTML table / PDF / CSV / Excel / interactive tool only
   - First and latest edition found:
   - How often it is updated (as the page states; "not stated" if it does not say):
   - Terms: any statement about reuse on the page or the site's policy page (quote it). U.S. government works are
     generally public domain; note anything that says otherwise.
   - Can it be obtained without scripting the publisher's site?  yes via <archive / bulk download / manual save>  |  no
   - Parsing effort: S / M / L, and the main difficulty
   - What it would let us show (one sentence) — and what it must NOT be used for (for example: estimating a wait)
   - Gray areas (anything unclear; state the conservative choice)
   - Verdict: GO / NO-GO / LATER, with one sentence of reasoning
   ```
3. If you **could not open** a page in this session, write "Not read in this session" under it and give no verdict.
   Do not fill the template from memory.
4. End the document with a ranking table: source, verdict, effort, the story it feeds (S-704, S-705 or S-706).
5. Append to `docs/DECISIONS.md` one row per GO verdict marked **PROPOSED** (the owner confirms before ingestion starts).
6. Update the three dependent story files (`S-704.md`, `S-705.md`, `S-706.md`): in each "Before you start" section,
   replace "the source chosen in S-701" with the actual source name and address, or set the story to
   `BLOCKED (S-701 verdict: NO-GO)`.

## Acceptance

- [ ] Every address was opened in this session and is written exactly as opened.
- [ ] Each has a verdict with reasoning; gray areas are flagged with the conservative choice.
- [ ] A ranking table links verdicts to S-704, S-705, S-706; those story files are updated.
- [ ] No data was downloaded in bulk and no code was written.

## Pitfalls
- `uscis.gov` and `travel.state.gov` refuse scripted requests. Reading a page in a normal browser tool as a person would
  is fine; writing a fetcher for them is not. For such sources the only acceptable routes are an Internet Archive copy
  or a file a person saves (as with the bulletin).
- A source that exists only as an interactive tool (no table, no file) is a NO-GO for ingestion; it can still be a link-out (S-703).
- Demand counts and cut-off dates must never be combined into a waiting-time estimate (decision D27). Say so in each "must NOT be used for".
