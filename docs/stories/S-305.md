## Goal
On every category × area page, describe how the Final Action Date actually moved over the last 12, 24 and 60
months: typical monthly movement, best and worst month, how often it stood still or went backwards.
This is **history only**. No projected date, no "at this rate", no waiting-time estimate, anywhere.

## Definitions (implement exactly)
Input: `points` = `dataset.series(line.key, 'finalActionDates', area.key)`, `latest` = `dataset.latestPeriod`,
`windowMonths` = 12, 24 or 60.
- The window is the periods `latest − windowMonths + 1 … latest`.
- A **step** is a pair (month − 1 → month) where month is in the window and **both** months have a point.
- For each step call `describeChange(current, previous)`:
  - `days` is a number → a **dated step** (0 counts as "no movement"; negative is a move back);
  - label "Became current" / "Available again" → counted as `opened`;
  - label "Became unavailable" / "Cut-off imposed" → counted as `closed`.
- Result:
  ```
  { windowMonths, steps, missingSteps,            // steps counted; steps skipped because a month is absent
    medianDays,                                    // median of dated steps' days (integer; null when no dated step)
    best: { period, days } | null,                 // dated step with the largest days
    worst: { period, days } | null,                // dated step with the smallest days
    noMovement, movedBack,                         // dated steps with days === 0 / days < 0
    opened, closed,                                // counts as defined above
    monthsCurrent, monthsUnavailable,              // points in the window whose value is 'Current' / 'Unavailable'
    includesUnverified }                           // any point in the window with verified === false
  ```
- Median of an even count = the mean of the two middle values, rounded to the nearest whole day.
- If `steps < windowMonths / 2` the window is "not enough data".

## Pitfalls
- Do not divide the gap between a date and "today" by the pace. That is exactly the estimate this site refuses to give.
- `formatDays` prints a sign; a median of 0 should read `no movement`, not `+0 d`.
- Many windows currently have missing months (withheld legacy data). "Not enough data" is the honest output; do not fill gaps.
