# S-601 Sponsor slot and advertise page

| | |
|---|---|
| Status | READY |
| Size | S |
| Difficulty | Routine |
| Phase | 5 Scale and monetize |
| Needs | nothing to build. Selling the slot is an owner action (trigger in `docs/LAUNCH.md`: 10k monthly visitors or a first inbound request). |

## Goal
One clearly labeled, flat-fee sponsor block, configured at build time and absent by default, plus an
`/advertise/` page that says what is and is not for sale. Decision D26: sponsorship only; no data, rankings
or attorney referrals are ever sold.

## Settings
| Variable | Rule |
|---|---|
| `SPONSOR_NAME` | 1–60 characters |
| `SPONSOR_LINE` | 1–120 characters, plain text |
| `SPONSOR_URL` | `https:` only |
| `SPONSOR_CONTACT_URL` | `https:` or `mailto:`; where a prospective sponsor writes. Controls the `/advertise/` page. |

The sponsor block appears only when the first three are all valid. The `/advertise/` page is built only when
`SPONSOR_CONTACT_URL` is valid.

## Files to touch
`src/site/config.js` (create if S-403 has not; pure functions that read an env object), `scripts/build-site.mjs`,
`src/site/layout.js`, `src/site/pages.js`, `src/site/format.js` (`urls.advertise`), `src/site/site.css`, `.env.example`,
`test/site.test.js`.

## Steps
1. `sponsorConfig(env)` → `{ name, line, url } | null` and `sponsorContact(env)` → `string | null`, with the rules above
   (trim; reject anything containing `<` or `>`). Put both on `site` (`site.sponsor`, `site.sponsorContact`) and in the `SiteContext` typedef.
2. `src/site/layout.js`: between `</main>` and `<footer>`, only when `site.sponsor`:
   ```html
   <aside class="sponsor wrap" aria-label="Sponsor">
     <span class="sponsor-label">Sponsor</span>
     <a href="…" rel="sponsored noopener">NAME</a> <span class="sponsor-line">LINE</span>
     <a class="sponsor-why" href="/advertise/">About sponsorship</a>   <!-- only when the advertise page exists -->
   </aside>
   ```
   It is outside `<main>`, so it is never inside a table, a result or the article text.
3. Do not show the sponsor block on: `/disclaimer/`, `/privacy/`, `/404.html`, and any `/embed/` page (pass `sponsor: false`
   from those pages; add an optional `sponsor` boolean parameter to `layout`, default true).
4. `advertisePage({ site })` at `urls.advertise = '/advertise/'`:
   - `<h1>Sponsor VisaPulse</h1>`
   - **Who reads it** — "People waiting on a U.S. immigrant-visa priority date, the employers who sponsor them, and
     immigration attorneys and paralegals." No visitor numbers unless the owner supplies them through a setting
     (do not invent an audience size; leave the sentence "Current visitor numbers on request.").
   - **What is offered** — one text sponsor line shown on most pages, labeled "Sponsor", one sponsor at a time, flat monthly fee.
   - **What is not for sale** — the data; the order or content of any table; rankings; attorney referrals or leads;
     email addresses; anything presented as editorial content. Sponsors have no say over what the site publishes.
   - **Who we will not accept** — anyone promising visa outcomes, selling "guaranteed" results or predictions, or
     anything unlawful.
   - **Get in touch** — a link to `site.sponsorContact`.
5. `site.css`: `.sponsor` — a bordered, muted strip; `.sponsor-label` small caps; must wrap cleanly at 375 px.
6. Footer navigation: add "Sponsor" → `/advertise/` only when the page exists.
7. `.env.example`: the four variables with comments. `npm run check`.

## Tests to add
- Default `site` (`sponsor: null`, `sponsorContact: null`): no page contains `class="sponsor`, `rel="sponsored`, or `/advertise/`.
- With a sponsor: a bulletin page contains `rel="sponsored noopener"` and the label `Sponsor`; the disclaimer page does not.
- The sponsor markup appears **after** `</main>` in the document (compare string indexes).
- `sponsorConfig` rejects an `http:` URL, an over-long line, and text containing `<`.

## Acceptance
- [ ] No sponsor markup by default (test).
- [ ] When configured: one labeled block, link marked `rel="sponsored noopener"`, outside `<main>`, absent on legal pages.
- [ ] `/advertise/` exists only with a contact address, and states the audience, the single flat-fee slot and what is not for sale.
- [ ] `npm run check` green in both configurations (`SPONSOR_… npm run build && npm run check:site`); 375 and 1280 checked.

## Pitfalls
- Never label the block "Partner", "Recommended" or "Trusted": it is an advertisement and must say "Sponsor".
- No sponsor logo images in this story (image hosting, sizing and tracking pixels are separate risks).
- Do not add affiliate links. That needs a legal review first (DECISIONS O5).
