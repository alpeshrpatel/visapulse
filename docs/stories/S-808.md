# S-808 "Cite this page" and a press/fact sheet

| | |
|---|---|
| Status | READY |
| Size | S |

| Why (growth) | Attorneys, journalists and researchers link to what is easy to cite. A ready citation and a fact sheet turn the provenance work into backlinks. See `docs/growth/OUTREACH.md`. |

## Goal
1. A "Cite this page" block on bulletin pages and category × area pages with copy-ready citations that credit
   the State Department first.
2. A `/cite/` page: how to cite, what the data is, and a fact sheet generated from the dataset.

## Citation formats (only when `site.siteUrl` is set)
- Plain: `U.S. Department of State, Visa Bulletin for <Month Year>, as structured by VisaPulse, <page URL>.`
- For a category × area page: `<code> <area> cut-off dates, U.S. Department of State Visa Bulletin (<first Month Year>–<latest Month Year>), as structured by VisaPulse, <page URL>.`
- HTML link: `<a href="<page URL>"><page title></a> (VisaPulse, from the U.S. Department of State Visa Bulletin)`
- Official source line: `Official source: <bulletin.officialSourceUrl>`

## Files to touch
`src/site/components.js` (`citeBlock`), `src/site/pages.js` (`citePage`, placements), `src/site/format.js` (`urls.cite`),
`scripts/build-site.mjs`, `src/site/layout.js` (footer link), `src/site/site.css`, `test/site.test.js`.

## Steps
1. `citeBlock({ site, title, path, plain, officialUrl })` returns nothing without `site.siteUrl`; otherwise a
   collapsed `<details class="cite"><summary>Cite this page</summary>` with the formats above, each inside a read-only
   `<textarea rows="2">` with an `aria-label` ("Plain citation", "HTML link"), plus the official source line as a link.
2. Place it at the bottom of `bulletinPage` (not on the home page) and `lineAreaPage`.
3. `citePage({ site, dataset })` at `/cite/` (built always; it does not need `SITE_URL`):
   - `<h1>Citing VisaPulse</h1>`
   - **Cite the government first** — "The cut-off dates are published by the U.S. Department of State. VisaPulse
     restructures them and records where each month was read from. When you cite a number, cite the official bulletin
     for that month; mention VisaPulse if you used our tables, charts or files."
   - **How to check a number yourself** — the three steps a reader can take: open the page's official source link;
     open the archive snapshot; compare the cell. Link to `/methodology/`.
   - **Fact sheet** (all values computed at build time; no typed numbers): months covered (first and latest
     period); months verified against the official page; categories and areas with pages (counts of `LINES` and `AREAS`);
     charts; file formats (JSON per month, one CSV); licence statement (same words as the open-data page).
   - **Use of charts and tables** — "You may reproduce our charts and tables with a link back. Please do not present
     them as predictions."
   - **Contact** — "Corrections and questions:" + the feedback form note when `site.feedbackEndpoint` is set; otherwise
     omit the section.
4. Footer navigation: "Cite" after "Open data". Register the page.
5. `npm run check`; then `SITE_URL=https://example.org npm run build && npm run check:site`.

## Tests to add
- Default `site`: no page contains `class="cite"`.
- `liveSite`: the EB-2 India page contains the plain citation with `https://example.org/priority-dates/eb2/india/`
  and the official source link; the June 2025 bulletin page's citation names "Visa Bulletin for June 2025".
- `citePage` fact sheet numbers equal `dataset.periods.length` and `dataset.verifiedPeriods.length`.

## Acceptance
- [ ] "Cite this page" on bulletin and category × area pages when the site URL is known; absent otherwise.
- [ ] Citations credit the State Department and include the official source.
- [ ] `/cite/` exists with a build-time fact sheet and is linked in the footer.
- [ ] `npm run check` green in both configurations.

## Pitfalls
- Do not include an "accessed on" date generated at build time: it would be wrong for the reader. Leave it to them.
- No visitor statistics, awards or testimonials on the fact sheet. Only facts about the data.
